# arbi — stand down — `/arbi-close`

Run at the end of a working session so the next wake starts from truth.

1. **End state.** Branch, ahead-of-main, open PRs and checks, working tree, `make check`.
2. **Outcome.** What the last ONE THING was, what was done, whether it landed and worked (done / partial / deferred / superseded).
3. **Update the owning issue** with evidence, decisions and blockers. Do not create a parallel tracker.
4. **Handoff** of about 500 words under docs/handoffs/: objective, completed, decisions, files/branch/PR, verification, blockers, outstanding asks, next action. No transcripts, logs or secrets.
5. Tell James to open a fresh chat with only the handoff and standing instructions; never claim a window opened unless it did.
